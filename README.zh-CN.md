# CastLink 投屏

[English](README.md)

CastLink 是一款 Android 局域网投屏应用：**发送端 + 接收端 + iOS AirPlay 接收，三合一，装一个 APK 就够**。手机投电视、iPhone 隔空播放镜像、任意文件推送——全走局域网，不经过云端，无需账号。

## 使用说明

### 接收端（电视 / 盒子 / 备用手机）

安装 CastLink 并打开。待机页会显示：

- **二维码**——任意手机扫码打开文件上传页
- **4 位 PIN 码**——每次投屏或镜像连接都需要输入
- **Wi-Fi 名称和 IP 地址**

保持这个页面开着就行，设备已可被发现。

### iPhone 投屏（AirPlay）

1. 确认 iPhone 和接收端连的**同一个 Wi-Fi**。
2. 打开**控制中心 → 屏幕镜像**。
3. 选择待机页上显示的 CastLink 设备名。
4. 输入电视上显示的 4 位 PIN 码。

电视全屏播放 iPhone 画面，用完在控制中心断开即可。

> 如果 iPhone 反复要 PIN 码但连不上：确认接收端 CastLink 还在前台、两台设备在同一网络。

### Android 投屏

1. 打开 CastLink → **把本机屏幕投出去**。
2. 从发现的设备列表选接收端（或点**手动输入 IP**）。
3. 输入接收端的 4 位 PIN 码。
4. 在系统弹窗中允许录屏。

以 720p/30fps 镜像画面，通知栏点**停止**结束投屏。

### 文件投放

在接收端待机页：

1. 任意手机扫二维码，或浏览器打开 `http://<接收端IP>:8756/`。
2. 选择任意文件上传——视频、音频、APK、文档都可以。
3. 接收端自动处理：
   - **视频/音频** → 内置播放器打开
   - **APK** → 提示安装（需允许"安装未知应用"）
   - **其他文件** → 系统默认应用打开

收到的文件在 App 的**媒体**标签页里能找到，点一下重新打开。

### 更新

CastLink 每天自动检查一次更新（可在设置里开关）。有新版本会弹出更新说明，点**立即更新**下载安装。

也可以手动检查：**设置 → 在线更新 → 检查更新**。

### 设置

- **设备名称**：显示给其他设备的名字（AirPlay 列表、设备发现）
- **PIN 码**：查看或重新生成 4 位 PIN
- **语言 / Language**：中文或英文，即时切换
- **下载镜像**：更新下载慢可以换镜像源

## 功能

- Android 发送端 + 接收端 + AirPlay 接收，单个 APK
- AirPlay：PIN 配对（SRP）、FairPlay 握手、H.264 + AAC/ALAC
- HTTP 文件投放：任意文件类型，接收端自动分发
- 在线更新（国内镜像加速）
- NEBULA UI：手机竖屏/横屏、电视/车机大屏适配
- 中英双语，即时切换
- 内置崩溃上报和诊断工具

## 已知限制

- DRM 内容（Netflix、Disney+、Apple TV…）永远投不了——系统限制，不是 bug。
- Android 发送端目前 720p/30fps 纯视频。
